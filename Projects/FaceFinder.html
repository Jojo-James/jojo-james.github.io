FaceFinder

Project information

  • Category: Web App
  • Client: Personal Project
  • Project date: 15 October 2026
  • Tech Used: Python, FastAPI, SQLite, InsightFace
  • Report: Click to view

FaceFinder is a web application intended to help event attendees find photographs in which they appear. An organizer creates an event and imports photographs. FaceFinder detects faces, stores numerical face embeddings, and compares an attendee-provided selfie against embeddings indexed for that event. The attendee receives a gallery of likely matches and can view or download images.

The project uses a Python FastAPI backend, SQLite, local image files, and InsightFace. Browser pages support attendees, organizers, photo management, results, and Contact Us. Google Photos Picker allows an organizer to select media; selected images are imported, saved locally, and indexed.
